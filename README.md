# Sistema de Gestión de Turnos

## Trabajo de grado

Sistema de software orientado a la optimización de la gestión de clientes
y al mejoramiento de la eficiencia en la atención de entidades de servicio,
tomando como contexto principal el sector bancario.

## Objetivo general

Desarrollar un sistema de software enfocado a la optimización de la gestión
de clientes en entidades de servicio y al mejoramiento de la eficiencia en
la atención.

## Componentes principales

- Backend
- Frontend
- Aplicación móvil
- Módulo de Primer Contacto (MPC)
- Pantalla de visualización de turnos
- Consola de atención para empleados
- Base de datos
- Sistema de pruebas

## Tecnologías principales

- Python
- FastAPI
- PostgreSQL
- React
- Node.js
- Git
